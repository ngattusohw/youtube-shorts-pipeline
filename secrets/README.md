# Secrets

Place your YouTube API credentials here. These files are gitignored.

## Required files

| File | Description |
|------|-------------|
| `client_secrets.json` | OAuth 2.0 client credentials from Google Cloud Console |
| `token.json` | Auto-generated after first authentication (optional to copy) |

## Setup

1. Download OAuth credentials from [Google Cloud Console](https://console.cloud.google.com/)
2. Rename to `client_secrets.json`
3. Place in this folder
4. Run any upload command - browser will open for auth
5. `token.json` will be created automatically
