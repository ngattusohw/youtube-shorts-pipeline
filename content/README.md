# Content Folder

Place your source video files here.

Supported formats:
- `.mp4` / `.MP4`
- `.mov` / `.MOV`

Video files in this folder are gitignored. Transfer them manually to each machine.

## Recommended workflow

1. Copy source videos here
2. Start Claude Code session from repo root
3. Describe what edits you want
4. Claude will process and output to `generated/`
